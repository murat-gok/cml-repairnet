# Data and licensing notes

- Article source data are downloaded from the publisher and retain the article's terms.
- PRIDE/ProteomeXchange files retain repository and submitter terms.
- UniProt and RCSB PDB records retain their respective database terms.
- The repository `.gitignore` excludes downloaded third-party files by default.
- Commit only manifests, checksums, scripts, metadata and independently generated outputs unless redistribution is explicitly permitted.
- The original CMLase study reports a patent application. CML-RepairNet's computational prediction code does not grant rights to manufacture, use or commercialize patented enzyme variants.
